Download thug-vita-port

Tony Hawk's Underground is one of the most beloved skateboarding games ever made, and this project gives it a new home on Sony's handheld. Instead of streaming the game or layering it inside another program, thug-vita-port runs the game directly on the PS Vita hardware itself. That means fast loading, responsive controls, and a genuine handheld skate session that feels right in your hands.

You do not need to be a programmer to use this. You do not need to compile anything, write commands, or edit configuration files. If you can download a file on Windows and copy it across with a USB cable, you can do this. Everything below is written step by step, in the order you should do it.

✨ What This Application Does

thug-vita-port is a homebrew project: a piece of software built by and for the PS Vita community. It takes the classic Tony Hawk's Underground experience and delivers it as a native application on the Vita, so the handheld's own processor and graphics chip do all the work.

  • Runs natively: The game is built for the PS Vita itself, not emulated or streamed from a computer.
  • Fully portable: Once the files are on your Vita, you can play anywhere — on the bus, on a plane, or on the couch with no PC nearby.
  • Built with the Vita in mind: Created using the VitaSDK toolchain, which is the community-standard way to make real Vita software.
  • No account or subscription: The project is hosted openly and freely on GitHub.
  • Simple file transfer: Everything is moved from your Windows computer to the console with a standard USB cable.

📋 Before You Begin

Take two minutes to gather what you need. Doing this first makes the whole process smooth and avoids stopping halfway through.

  • A Windows computer with an internet connection and a free USB port.
  • A USB cable that can connect your PS Vita to that computer — the same style of cable you use for charging and data transfer.
  • A PS Vita console that is set up and ready to run homebrew applications.
  • Free storage space: around 2 GB of room on your memory card is a comfortable amount for the game files and save data.
  • About 15 minutes of time for the download and copy process.

Quick tip: Close any large programs on your computer and keep the PS Vita plugged in until the copy finishes. Interrupting the transfer halfway is the single most common cause of a game that will not start.

📥 Copying the Files to Your PS Vita

Now you will move the files from your Windows computer to your handheld. This is a straightforward copy-and-paste job, not an installation wizard.

  1. Unplug nothing yet. Connect your PS Vita to your computer using the USB cable and wait for Windows to recognise the device. A window confirming the connection will normally appear.
  2. Open File Explorer. Click the folder icon on your taskbar, or press the Windows key and type "File Explorer."
  3. Find your Vita. It will appear in the left-hand sidebar under "This PC," usually labelled with the console's name. Click it to open it.
  4. Open the folder you downloaded to in a second File Explorer window, so you can see the source and the destination side by side.
  5. Copy the application files across. Select the project folder, right-click, choose "Copy," then click into the Vita window, right-click, and choose "Paste." Leave the computer alone while the progress bar runs.
  6. Wait for the transfer to finish. On Windows, a small dialog tracks progress. Do not unplug the cable until it closes completely.
  7. Disconnect safely. Once the copy is done, eject the device from the system tray and unplug the cable.

🎮 Launching the Game on Your Vita

With the files safely on the console, unplug the cable and pick up your PS Vita. Return to the home screen, where your applications are listed. Find the thug-vita-port entry in the list and tap it to launch the game.

The first launch takes a little longer than later ones, because the console is reading the game files for the first time. Give it a moment — do not tap the icon repeatedly, as that can confuse the loader. Within a short while the game will appear on screen and you can start skating.

Progress you make in the game is saved on your memory card, so you can close the application and come back later without losing anything. Treat the game like any other app on your Vita: close it properly from the home screen when you are done playing.

🛠️ Troubleshooting Tips

If something does not go to plan, work through these checks in order. In most cases the problem is a file that did not copy across fully.

  • The game does not appear on the home screen. The files were probably pasted into the wrong folder. Reconnect the Vita and confirm the project folder sits in the same place as your other applications, not loose inside a generic documents area.
  • The game starts and immediately closes. Delete the copy on your Vita and repeat the transfer from scratch. A partial copy is the usual culprit, and a clean second attempt fixes it nearly every time.
  • The transfer stops or fails partway. Try a different USB port, preferably one directly on your computer rather than a hub. Also check that your memory card has enough free space — running out of room mid-copy corrupts the files.
  • Windows does not see the console. Unplug the cable, wait a few seconds, and plug it back in. Try a different cable if you have one; some cables carry power only and cannot move data.
  • The game feels sluggish on the first attempt. Restart the console, then open the game again. A fresh start clears temporary memory that other apps may be holding.

💬 Frequently Asked Questions

Do I need a fast computer to use this?

No. Your computer is only used to download the files and copy them to the console. The game runs entirely on the PS Vita, so even an older laptop is fine for this task.

Can I play without the USB cable?

You need the cable once, to move the application files onto the console. After that first transfer, the game is on your Vita and works anywhere with no computer involved.

Will this delete my other games and saves?

No. Copying these files adds a new application alongside what is already on your console. Your existing games, photos, music, and save data stay exactly where they are.

How much space will the game take up?

Plan for roughly 2 GB of free room on your memory card. That covers the game files plus a comfortable buffer for your save data as you progress.

How do I get updates?

New versions are published on the project's GitHub page. To update, simply download the newest files and copy them over the old ones, replacing them when Windows asks.

thug-vita-port exists because of the PS Vita homebrew community — people who spend their own time building tools, documentation, and ports so that a discontinued handheld keeps getting new life. The project is built with VitaSDK, the community's open toolchain for creating native Vita software.
